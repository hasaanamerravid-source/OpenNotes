# The languages of the interface

OpenNotes speaks five languages: English, German, Spanish, Russian and Simplified
Chinese. The language is chosen in **Settings → General**.

This document explains how the translation works and how to change it.

## How it is built

```
src/shared/i18n/
  en.ts              the English catalogue — the source of truth
  index.ts           the runtime: translate(), interpolate(), formatDate(), …
  locales/
    de.json          the German translation
    es.json          the Spanish translation
    ru.json          the Russian translation
    zh-CN.json       the Simplified Chinese translation
```

The runtime has no framework dependency, so the main process uses it as well:
the native menu is written in the language of the interface.

The renderer adds `src/renderer/src/core/i18n.ts` with three things:

| Function | What it does |
| --- | --- |
| `useT()` | The translator of a component. The component is drawn again when the language changes. |
| `setLocale(locale)` | Changes the language, saves it and tells the main process about it. |
| `applyDocumentLocale(locale)` | Sets `lang` and `dir` on the document, so that the browser and the screen reader know what to do. |

## The rules of a message

| Rule | Example |
| --- | --- |
| The key names the place it belongs to | `panel.problems`, `status.line`, `cmd.file.save` |
| The value is plain text | `'Open a file…'` |
| A value is put in with `{{name}}` | `'Saved {{name}}'` |
| The placeholders are never translated | `t('toast.saved', { name: 'notes.md' })` |
| The ellipsis is the character `…` | `'Open…'`, not `'Open...'` |

A key that is not translated yet falls back to the English text, so a half
finished translation never breaks the application. A key that does not exist in
the English catalogue is an error.

## Adding a string

1. Put the English text into `src/shared/i18n/en.ts`, in the group it belongs
   to. The groups are sorted, so that a translator can work through the file
   without touching the rest.
2. Use it in the interface:

   ```tsx
   const t = useT()
   return <button title={t('title.save')}>…</button>
   ```

3. Translate it. The quickest way is to let the tooling show the missing keys:

   ```bash
   node scripts/i18n.mjs missing de
   ```

   The command prints a JSON object with the English text of every key that the
   language does not have yet. Fill it in and merge it:

   ```bash
   node scripts/i18n.mjs fill de my-translations.json
   ```

4. Check the result:

   ```bash
   npm run i18n:check      # every language file must match the catalogue
   npm run i18n:coverage   # how much is translated
   ```

## Adding a language

```bash
node scripts/i18n.mjs template es     # writes locales/es.json with every key
```

Fill in the file and check it with `npm run i18n:check`. The new language is
offered in the settings as soon as it is in `src/shared/i18n/index.ts`:

```ts
export const LOCALES: LocaleInfo[] = [
  { id: 'en', englishName: 'English', nativeName: 'English', direction: 'ltr', tag: 'en' },
  // …
  { id: 'es', englishName: 'Spanish', nativeName: 'Español', direction: 'ltr', tag: 'es' }
]
```

A language that is written from right to left has `direction: 'rtl'`. The
document then carries `dir="rtl"`, and the interface is mirrored by the
browser.

## What is not translated

| Thing | Why |
| --- | --- |
| The name of a file | It belongs to the user, not to the application. |
| The name of a language (`JavaScript`, `Markdown`) | It is a proper noun. |
| The name of a file format (`keybindings.json`, `.opennotes.json`) | It is a path. |
| The content of the editor | It belongs to the user. |
| The names of the shortcuts (`Ctrl+S`) | They are the same on every keyboard. |
| The names of the encodings (`UTF-8`, `CRLF`) | They are standard names. |

## The tests

`npm run i18n:check` proves that

* every language file only holds keys that exist in the English catalogue,
* no value is empty,
* every placeholder of the English text is also in the translation.

The in-app suite (`npm run test:app`) proves that the language can be changed
at run time, that a right-to-left language turns the window around and that
the native menu follows.
